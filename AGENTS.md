# Project AI Entry Point

This repository is managed with the Portable Project Context Specification from ChatGPT Development OS.

Canonical repository: `zzpsah/automation-suite`.

This is a multi-module automation repository. Before substantial work:
1. Read `.ai/manifest.yaml` and `.ai/STATE-INDEX.md`.
2. Read `.ai/PROJECT.md`, `.ai/CURRENT-STATE.md`, decisions/tasks/architecture.
3. Read root `CLAUDE.md` and relevant module documentation when applicable.
4. Identify the exact module before changing code.
5. Inspect source, tests, workflows, and Git history.

Do not mix unrelated module changes in one task. Never store credentials, tokens, cookies, private school documents, or unnecessary personal/student data in `.ai/`.

`.ai/STATE-INDEX.md` is generated by Development OS automation and should not be manually edited.
