## Recovery procedure

1. Open `zzpsah/automation-suite`.
2. Open `global-automation/ocr/` for the shared OCR project on `main`.
3. For the active OCR development version, switch to `feature/global-sarkari-ocr`.
4. Open `global-automation/ocr/` on that branch.
5. Do not create a second OCR copy under another project.

The repository and folder path above are the canonical references for future work.
