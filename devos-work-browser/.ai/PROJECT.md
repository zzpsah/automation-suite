# Project

Name: DEVOS Work Browser
Type: Windows desktop browser + future agentic automation workstation
Module path: `devos-work-browser/`

## Product intent
Build a genuinely custom DEVOS browser experience. Chromium/WebView2 is an underlying rendering technology only; the application shell and future automation/runtime belong to DEVOS.

The user should eventually give goals rather than click sequences, but the first releases prioritize deterministic browser control, verification, checkpoints and recovery before natural-language planning.

## Non-goals for F0
No BrowserOS shell, extension overlay, side panel, PDF suite, image suite, MCP, multi-agent, FTP/SFTP, printing, OCR or workflow recorder.
